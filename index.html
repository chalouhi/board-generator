Board Generator

Give it one file of cards. It draws the board: columns of cards, with the ones waiting for a person in a strip on top. Click a card to open it. Your file never leaves this browser.

Drop a file here or JSON or XML, as described in the file-format guide.

Three ways to use it: this page; the command board <file> --svg board.svg --pdf board.pdf; or include src/board.js in your own page and call BoardGenerator.draw(place, text). MIT licence. Source and guides.
